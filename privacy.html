Privacy policy

Home Base is a personal app used only by its owner, on the owner's own computer.

What it accesses

With the owner's permission, Home Base uses the Gmail API to read the owner's emails about orders and payouts, to add labels to those emails, and to send email alerts to the owner.

How the data is used and stored

  • Gmail data is stored only on the owner's own computer and is used only to show the owner their own orders, payouts and alerts.
  • No Gmail data is sold, shared with or sent to anyone else, and none is used for advertising.
  • Home Base's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.
